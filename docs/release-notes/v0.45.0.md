# Release notes — v0.45.0

- Added shared api-client methods for **argument participants**, so the web and
  mobile apps manage collaborators through one contract instead of two:
  `getArgumentParticipants` (list the owner and editors involved in an argument),
  `addArgumentEditor` (promote a user to editor), and `removeArgumentParticipant`
  (remove an editor, or step yourself down). Adds the `AddParticipantRequestSchema`
  request body.
- Added shared api-client methods for **registration invitations and promo codes**:
  `activateRegistrationInvite` (redeem an invitation or promo code, with the
  required agreement acknowledgements) and `issueInvitation` (create an invitation
  code to share). Both apps now redeem and issue invites through one implementation.
