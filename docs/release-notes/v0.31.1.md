# Release notes — upcoming

## Premises now read top-to-bottom

When viewing an argument, its premises are ordered so the argument unpacks as you
read down: the conclusion first, then the premises that support it, then the
premises that support those, and so on. Following the reasoning no longer means
scrolling back up to find where a claim was established — a premise's support
sits directly beneath it. Arguments whose structure doesn't fit a clean tree,
and any rebuttals, still order as well as possible, with anything left over
listed after the main chain.
