# Release notes — v0.31.0

## Public historical-figures showcase dataset

Added a public, community-revisable dataset of well-known public-domain authors
(Socrates/Plato and John Stuart Mill) and the central argument of a canonical
text each one wrote. Each argument was drafted by running its source text
through the argument-ingestion pipeline. Alongside each figure we now ship
human-readable Markdown — about the author, the full public-domain source
document, and about that document — which travels with the package so consumers
can display it. The dataset and a small authoring vocabulary for hand-editing
arguments ship as importable entry points, so the structures and their context
can be browsed, reused, and improved through pull requests.

## Curated-user marker on the user schema

The user shape now carries a nullable `curationId`, a human-readable id that
marks a synthetic/curated account (such as a showcase historical-figure author).
It is `null` for normal users.
