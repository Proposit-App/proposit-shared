# Upcoming release notes

### Features

- `apiClient.deleteUser()` on `@proposit/shared/api-client`. Issues `DELETE /api/v1/user/me` and returns the deleted user, validated against `UserSchema`. Takes no arguments; auth is handled by the consumer-supplied `fetchImpl` (web cookies on server, Bearer token on mobile). Requested by `proposit-server` to unblock `proposit-mobile`'s App Store Guideline 5.1.1(v) account-deletion flow — Apple-token revocation for SIWA-linked accounts is handled server-side by the existing `/me` route.
