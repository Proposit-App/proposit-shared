# Release notes — v0.46.0

- Added **inline review resolution** for the argument text view. A new
  `buildInlineReviewOverlay` helper merges core's usage-based default
  assignments, the reader's own claim reactions, and their in-review overrides
  into one effective true / false / unknown value per claim
  (`override ?? reaction ?? default`), and tells the UI where each value came
  from — the reader's own input (`"user"`) or a derived default (`"default"`).
  It also evaluates the merged assignment with every inference accepted, so the
  overlay carries each claim's propagated `unknown → true` value and the
  argument's evaluation grade for the web and mobile apps to render identically.
- Requires `@proposit/proposit-core` `^3.1.0`, which supplies the usage-based
  default derivation and evaluation grading this builds on.
