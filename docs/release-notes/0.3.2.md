# Upcoming release notes

### Bug fixes

- `apiClient.getAllArguments(...)` now passes the absolute URL (origin + path + query) to the consumer-supplied `fetchImpl`, instead of the path-only string `/api/v1/argument?...`. The path-only form relied on browser `fetch()` resolving against `window.location.origin`, so it worked on `proposit-server` (web) but failed on `proposit-mobile` (React Native, no `window.location`) with `TypeError: Network request failed`. Reported by `@proposit/proposit-mobile` during Phase 1 / 1F simulator validation. Once published, mobile can revert its temporary diagnostic workaround in `useArgumentsList`.
