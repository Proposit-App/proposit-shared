# Release notes — v0.36.0

## Read a claim's reaction stance — per claim or in bulk

The api-client gains two read methods for claim reactions, complementing the
existing `createClaimReaction` / `deleteClaimReaction` writes:

- `getClaimReaction(argumentId, version, claimId)` returns one claim's public
  stance counts plus the caller's own selection (`{ counts, own }`).
- `getClaimReactionMap(argumentId, version)` returns the same shape for every
  claim in an argument version at once, as a map keyed by `claimId` — the new
  `ClaimReactionMapResponse` (`Record<claimId, { counts, own }>`), which reuses
  `ClaimReactionGetResponse` as its value.

Purely additive — pin with `^0.36.0`.

> The bulk `GET …/claim-reactions` route is served by a companion
> `proposit-server` change; `getClaimReaction` targets the already-live
> per-claim route.
