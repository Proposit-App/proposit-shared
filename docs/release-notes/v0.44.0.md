# Release notes — v0.44.0

- Added the shared **derived-view layer** — new modules that give the web and
  mobile apps one canonical implementation of the derivations and rendering built
  on top of the logic engine, so the two apps stop drifting apart:
    - `@proposit/shared/engine/derive` — counterargument/tab partition,
      lone-conclusion detection, and client-side repair detection.
    - `@proposit/shared/engine/render` — symbolic-formula rendering with a legend,
      markdown and plain-text export, and the citation display projection (type
      humanization, inline source labels, source description, byline parsing).
    - `@proposit/shared/engine/algebra` — changeset merge reconciliation and the
      propositional-variable symbol generator.
    - `@proposit/shared/engine/overlay` — the platform-neutral overlay / render-map
      item model and skeleton-overlay transform (each app supplies only its own
      presentational leaves).
- Graduated the optimistic claim-reaction math into the shared engine, so the web
  and mobile apps drive claim reactions off one tested implementation instead of
  two drifting copies.
- Added a machine-readable conflict signal for publish/archive: when an argument
  can't be published or archived because of its current state, the API now returns
  a coded envelope the apps can act on directly (e.g. "already published",
  "can't archive a published version", "superseded by a newer edit") rather than a
  bare message.
- Now built against `@proposit/proposit-core` 3.0.0 (peer dependency range
  `^3.0.0`).
