# Release notes — upcoming

## The argument assessment reads in one or two words

A review reports two findings, and the one about the argument used to be a
sentence: "Doesn't reach its conclusion". Both apps draw it in a chip a few
characters wide, beside the conclusion's own one-word value, so it now reads
the way its neighbour does — **Reaches**, **Falls short**, **Contradictory**.

The wording is shorter, not softer, and it deliberately avoids two readings the
longer version could not slip into. Nothing grades the author's work: a review
says what happened, and a positive finding can stand beside a premise the
reader rejected, so a word like "acceptable" would contradict the rejection
sitting next to it. And falling short is not impossibility — the usual reason
is that the reader left something unsettled, which they can change.

## Warning turns orange

The warning colour was a mustard yellow, which read as caution only faintly on
a canvas that already spends yellow-green on the main action. It is now an
orange, in both light and dark. Every warning surface in both apps takes it,
including the "falls short" chip, where it now sits clearly between the green
of an argument that reaches its conclusion and the red of one whose premises
contradict each other.
