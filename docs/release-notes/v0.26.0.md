# Release notes — v0.26.0

This release completes the shared-library half of the independently-versioned-claims work and adds the load-time guard behind the citation-placement fix.

- **Citations and axioms can no longer be used as freeform-premise nodes.** `PropositArgumentEngine` now rejects a citation- or axiomatic-typed claim placed in a freeform (`IMPLIES`) premise at construction time, so a malformed argument fails with a clear error instead of crashing downstream. Consumers building arguments from ingestion output get this guard for free.
- **Claim-versioning client API.** `createApiClient` gains `getLatestClaim`, `getLatestClaimVersion`, and `advanceClaimReference`, with their request/response schemas — fetch a claim's latest published version, detect a newer version, and advance a draft argument's reference to it.
- **Cleaner citation shape + claim-version pins.** `CitationClaimSchema` models the citation as a non-nullable IEEE-or-unparsed union with a nullable `url`; the derivation-premise schema pins the referenced claim version; claim-only forks may have a null `forkId`.

**Pre-1.0 note:** minor bump that may include breaking schema changes — pin with `^0.26.0`.
