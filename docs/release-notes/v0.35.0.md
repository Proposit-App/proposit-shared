# Release notes — v0.35.0

## Mobile session requests can now sign in with X (Twitter)

`MobileSessionRequest` is now a discriminated union on `provider`. Alongside the
existing `{ provider: "google" | "apple", idToken }` shape, it accepts a new
`{ provider: "x", accessToken }` member. X sign-in uses OAuth 2.0 (PKCE), which
yields an access token rather than an OIDC ID token, so the X request carries
`accessToken` and has no `idToken` — the fields are kept distinct rather than
overloading `idToken`.

The wire discriminator for the new member is the literal `"x"` (not `"twitter"`).
The stored provider identity `twitter` is a separate concept and is not a valid
value on this request.

Additive and non-breaking for existing google/apple callers — pin with `^0.35.0`.
