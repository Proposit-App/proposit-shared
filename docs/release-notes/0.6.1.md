# Release notes — v0.6.1

Patch release. Exposes the v0.10/v0.11 type discriminators on `TTextTreeItem` so consumers can render `CITATION` and `DERIVATION` badges without re-walking the snapshot. Background: `docs/change-requests/2026-05-07-text-tree-discriminators.md`.

## Why this is patch (and not minor)

Two fields added to existing union variants of an existing exported type. No public API removed, no signatures changed. Consumers that don't read the new fields keep working unchanged; consumers that do read them get the discriminator straight from the text-tree row instead of doing a side lookup against `snapshot.claims[…]` / `snapshot.premises[…]` at render time.

## What's new

### `TTextTreeItem.claim.claimType`

The `claim` variant now carries `claimType: "normal" | "citation"`, populated from `snapshot.claims[claimId].type`. Defaults to `"normal"` when the claim isn't found in the snapshot or its `type` field is absent (mirrors the engine's existing `c.type ?? "normal"` fallback in `getClaimsRecord`).

### `TTextTreeItem.premise-header.premiseType`

The `premise-header` variant now carries `premiseType: "freeform" | "derivation"`, populated from `snapshot.premises[premiseId].premise.type`. Defaults to `"freeform"` when absent (mirrors core's `bag.type ?? "freeform"` default in `argument-engine`). Note: `buildTextTree` continues to skip derivation premises in the flat walk (per v0.6.0), so in practice headers emitted by this path will be `"freeform"` — but the field is typed for both values to keep the variant honest about what `premiseSnap.premise.type` can hold, and to support future call sites that might emit headers for derivation premises.

## Migration impact

- **`proposit-server`:** if the web read view consumes `TTextTreeItem`, no source change needed — adding fields to a union variant is non-breaking on consumers.
- **`proposit-mobile`:** can drop the local `TBadgedTextTreeItem` union and the `augmentItem` helper introduced in sub-project 1I, in a follow-up cleanup PR after this release publishes.
