# Release notes — upcoming

## The worked example now says it isn't yours, on every app

The small illustrations attached to a review result are drawn with exactly the
same claim cards and pills as the argument you were reviewing. That is
deliberate — it is what makes the example transferable — but it means the only
thing telling you the illustration is not your own work is the wording around
it.

That wording lived in the web app alone. It now lives with the definitions, so
both apps carry it: the example is introduced as a made-up argument that is not
part of the argument you reviewed and none of which is yours, and its outcome is
labelled "Result of this example:" rather than a bare "Result:", which read as
though it were yours.
