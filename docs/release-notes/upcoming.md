# Release notes — upcoming

## Public historical-figures showcase dataset

Added a public, community-revisable dataset of well-known historical authors
(Socrates/Plato, John Stuart Mill, Martin Luther King Jr.) and the central
argument of a canonical text each one wrote. Each argument was drafted by running
its source text through the argument-ingestion pipeline and then lightly curated,
with a short human-written summary added. The dataset and a small authoring
vocabulary for hand-editing arguments ship as new importable entry points, so the
structures can be browsed, reused, and improved through pull requests.
