# Release notes — upcoming

## The rejection that did nothing can no longer be recorded at all

Last release stopped offering a rejection of the argument's own conclusion,
because that premise is always evaluated whatever verdict you record against it.
The verdict could still be written, though, and writing it hid a flagged
collision and let the review be finished. Recording it is now refused outright.
Nothing changes for accepting, which still means what it says.

## A finished review that you go on editing stops calling itself finished

Editing an answer from the results screen — which the "change your answer"
prompts invite you to do — left the review marked complete until something
re-checked it. Reopening it later and editing did the same. The mark now comes
off as soon as you change an answer, and goes back on when a fresh check clears
the review.

While a review is waiting to be re-checked it no longer shows a conflict screen
with nothing on it. It asks to be re-checked, which is what is actually true.

## "You assigned this" was claiming too much

Where a conclusion is built from more than one claim, answering any one of them
was reported as having assigned the conclusion — so a conclusion nobody had
given a value could be labelled "Unknown — You assigned this." It now reads
"Your answers contributed to this", which is what the review actually knows.
