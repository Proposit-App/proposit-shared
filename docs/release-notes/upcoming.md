# Release notes — upcoming

## A review result now comes with an explanation, not just a label

A review reports two things — what the conclusion came out to, and what the
argument achieved — and until now the apps could only show you the labels. The
words behind those labels now live here, so both the web app and the mobile app
can explain the same result the same way.

Each of the nine things you can be looking at carries three pieces: a definition
in ordinary words, a small worked example drawn in Proposit's own notation
(claim cards, the operator between them, the true/false/unknown pills, the
conclusion marked as the conclusion), and a short list of freely readable
further reading.

The definitions cover the readings people get wrong most often: that a true
conclusion beside an argument that didn't reach it is coherent rather than a
contradiction; that "it holds only because you assigned it" is a fact about the
argument, not a criticism of you; that rejecting a step says nothing about
whether what it concludes is true; and that an unknown is a gap you can go back
and fill, not a defeat.

There is also plain-words help for a step that is satisfied but passes nothing
on, and a way to state a failing case from the exhaustive check in the
argument's own claim titles rather than as raw data.
