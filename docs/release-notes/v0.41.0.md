# Release notes — v0.41.0

- The mobile-session contract now models two non-OAuth login paths — email
  one-time-code and a hidden testing-and-qa reviewer login — plus the OTP
  request-code step, so the mobile app can sign in reviewers who cannot use
  OAuth. Fully backward-compatible with existing Google/Apple/X requests.
