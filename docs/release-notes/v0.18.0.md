# v0.18.0 release notes

## `listTasks` — list a user's tasks

`createApiClient(...)` now exposes `listTasks(query?)` — a `GET /api/v1/task`
that lists the authenticated user's tasks with pagination. All query params are
optional: `argumentId` (UUID), `version`, `limit` (1–50, default 20), `offset`
(default 0). Absent params are omitted from the request URL rather than
serialized as `undefined`, and the documented defaults are applied server-side.

The response schema is exported at `@proposit/shared/schemas/api/task-list` as
`ListTasksResponseSchema` (`{ tasks, hasMore }`): `tasks` is the full
`TaskSchema` union (a user's list spans every task type), and `hasMore` drives
lazy-loading. This ships ahead of the consumer `/profile/tasks` page, which is
gated on this version; the server route, model query, and `taskActions` helper
ship independently.
