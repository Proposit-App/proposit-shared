# Release notes — v0.19.0

> Requires `@proposit/proposit-core` `^2.0.0`. Install the new core major
> alongside this release.

This release adopts the two-tier citation model from core `2.0.0`. A citation
claim can now carry either a fully structured IEEE reference or an
ingestion-extracted **unparsed** citation that has not yet been structured —
or, as before, no structured reference at all (a url-only claim).

## What changed for consumers

- IEEE reference types continue to be available from
  `@proposit/shared/schemas/model/references`; no import-path change is needed
  in server or mobile. (Internally the re-export now points at core's
  `extensions/citations/ieee` subpath, reflecting core's namespace move.)
- The new `TUnparsedCitation` type is re-exported alongside `TIEEEReference`,
  so code that branches on a citation can handle the unparsed tier through the
  same import path.
- `CitationClaim.citation` is now `IEEE | Unparsed | null`. Any code that
  pattern-matches on a citation's `type` should account for the `"unparsed"`
  discriminant in addition to the IEEE literals.
- `extractCitationTitle` transparently produces embeddable/display text for
  unparsed citations (preferring the raw text, falling back to a locator url).
