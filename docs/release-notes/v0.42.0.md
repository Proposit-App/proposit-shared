# Release notes — v0.42.0

- Hardened the new mobile email-OTP / testing-and-qa login schemas to reject
  malformed input at the wire boundary: empty or over-long emails, emails with
  no `@`, non-six-digit codes, and empty QA identities no longer validate. No
  type-level changes — existing well-formed requests are unaffected.
