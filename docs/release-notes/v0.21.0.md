# Release notes — v0.21.0

This release adds the run-level failure reason to the pipeline-status run
object.

## What changed for consumers

- **Pipeline status now carries the run-level failure reason.** The
  pipeline-status API's run object exposes `errorData`, the recorded cause when
  an import fails below the stage level, so clients can show _why_ a run failed
  instead of a generic message.
