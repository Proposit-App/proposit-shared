# Upcoming release notes

Patch release. Adds shared length-limit constants for the server's ATV-editable text fields — `ARGUMENT_TITLE_MAX_LEN` and `PREMISE_TITLE_MAX_LEN` (both 100) — and permissively raises `CLAIM_TITLE_MAX_LEN` from 50 to 100. `CLAIM_BODY_MAX_LEN` (500) is unchanged. Background: `docs/change-requests/2026-05-11-length-limit-constants.md`.

The change is strictly additive plus one permissive raise; existing rows that fit the old 50-char claim-title limit remain compliant under the new 100-char limit. No deprecations, no breaking changes, downgrade-safe.

## What changed

`src/consts/argument.ts` now exports four length-limit constants:

```ts
export const ARGUMENT_TITLE_MAX_LEN = 100 // new
export const PREMISE_TITLE_MAX_LEN = 100 // new
export const CLAIM_TITLE_MAX_LEN = 100 // was 50
export const CLAIM_BODY_MAX_LEN = 500 // unchanged
```

All four are re-exported through `@proposit/shared/consts` via the existing `export * from "./argument.js"` in `src/consts/index.ts`.

## Why this is permissive

`CLAIM_TITLE_MAX_LEN` was 50 in `0.7.1`. The only in-repo consumer flagged during change-request review was the legacy MUI flow view in `proposit-server` (`view/[argumentId]/[version]/components/flow/claim-node.tsx`), which uses the constant for a label suffix. Raising the limit relaxes that view's user-facing cap; existing DB rows ≤ 50 chars remain valid.

The two new constants did not exist before, so adding them cannot collide with prior behavior.

## Migration impact

- **`proposit-server`** — Once the dependency is bumped to `^0.7.2`, the Cluster C work can land:
    - Add a `validateMaxLengths()` route-handler utility in `src/utils/server/` that imports all four constants from `@proposit/shared/consts`.
    - Call it from the six ATV write routes (`POST /api/v1/argument`, `PUT /api/v1/argument/[id]/[v]`, `POST + PUT /api/v1/.../logic/premises[/{id}]`, `POST + PUT /api/v1/.../claims[/{id}]`).
    - Replace the legacy flow view's hardcoded `slotProps.htmlInput.maxLength: 50 / 500` with the constants so the bumped title limit takes effect consistently with the new server-side enforcement.
- **`proposit-mobile`** — No source change required beyond an eventual dependency bump.
