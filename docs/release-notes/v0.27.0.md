# Release notes — v0.27.0

## Argument Builder schemas — public export

`ArgumentBuilderRequestSchema`, `ArgumentBuilderResponseSchema`, and their variants
(`ArgumentBuilderReviewResponseSuccessSchema`, `ArgumentBuilderFinalizeResponseSuccessSchema`,
`ArgumentBuilderResponseRefusedSchema`) are now exported from `@proposit/shared/schemas/api/argument`.
Corresponding TypeScript types (`TArgumentBuilderRequest`, `TArgumentBuilderRequestResponse`,
`TArgumentBuilderFinalizeResponseSuccess`) are also available.

This makes the schemas available to consumers (server, mobile) that need to validate or
document the Argument Builder API contract. The schema structure itself is unchanged.
