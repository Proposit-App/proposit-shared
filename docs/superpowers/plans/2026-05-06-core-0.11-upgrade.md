# Core 0.11 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring `@proposit/shared` from 0.4.0 to 0.5.0, consuming `@proposit/proposit-core` ^0.11.0. Absorbs both core's v0.10 source-as-claim unification and v0.11 derivation premise discriminator in a single shared bump.

**Architecture:** Path A architectural unification — shared's `TSource` entity is dissolved into citation-typed `TClaim` records with URL/IEEE/contentHash data inline as claim extras. Level B derivation surface exposure — re-export `ManagedDerivationPremiseEngine` and `validateDerivationStructure` without adding shared-side mutation envelopes. Six-commit phased staging on a single branch (`feature/v0.5.0-core-0.11`), single PR. Each commit leaves `pnpm run check` green; ordering chosen so the schema source-to-citation rename and the engine `domainSources` removal don't strand mid-rename code in non-typechecking states. The full design with rationale is at `docs/superpowers/specs/2026-05-06-core-0.11-upgrade-design.md`.

**Tech Stack:** TypeScript 6.0, pnpm 10.23, vitest 4.1, TypeBox 1.1, prettier 3.8, eslint 9.39, `@proposit/proposit-core` ^0.11.0 (peer + dev dep).

**Two naming rules govern the rename throughout (do not deviate):**

1. **Shared yields to core when names collide.** Concrete: shared's existing `ClaimSchema.type` (values `"claim" | "conclusion" | "definition" | "criterion"`) is renamed to `kind` so core's `type: "normal" | "citation"` discriminator can occupy the canonical name.
2. **"Citing claim" / "source claim", never "cited claim".** Core's `CoreClaimCitationSchema` uses `citingClaimId` and `sourceClaimId`; shared's wire and engine surface follows.

This release brings `@proposit/shared` onto `@proposit/proposit-core` ^0.11.0, absorbing both core's v0.10 source-as-claim unification and v0.11 derivation premise discriminator in a single breaking bump. Consumers (proposit-server, proposit-mobile) coordinate on the upgrade — server's wave 1 PR ships the matching DB migration; mobile's bump is a substantive code change.

## What's changed

### Source-as-citation unification (Path A, mirroring core@0.10)

- `TSource` is gone as a separate entity. Citation metadata (URL, IEEE reference, content hash) lives as optional claim-extra fields on `TClaim` records with `type === "citation"`.
- `TClaimSource` is renamed to `TClaimCitation`. Edges have first-class `id` plus `citingClaimVersion` / `sourceClaimVersion` pinning, mirroring core's `CoreClaimCitationSchema`.
- `ArgumentDiff.sources` and `FullArgument.sources` are gone — citation claims show up in the existing `claims` array via the `type` discriminator.
- `ArgumentDiff.claimSources` → `claimCitations`. `FullArgument.claimSources` → `claimCitations`.

### `ClaimSchema.type` field rename

`ClaimSchema.type` (values `"claim" | "conclusion" | "definition" | "criterion"`) is renamed to `kind`, freeing `type` for core's `"normal" | "citation"` discriminator. The const `ClaimTypes` and schemas `ClaimTypesSchema` / `TClaimTypesSchema` rename to `ClaimKinds` / `ClaimKindsSchema` / `TClaimKindsSchema`. `ClaimSearchResultSchema.type` → `kind`.

### Premise type discriminator (mirroring core@0.11)

Every premise now carries a required `type: "freeform" | "derivation"` field. Derivation premises also carry a required `derivedClaimId`. Legacy premise data without `type` is rejected at the schema-parse boundary.

### v0.11 derivation surface re-exports (Level B)

`@proposit/shared/engine/derivation` re-exports `ManagedDerivationPremiseEngine`, `validateDerivationStructure`, `TVariableMaterializer`, and the v0.11 error code constants. No shared-side mutation envelopes around derivation flows yet — those wait for server wave 2.

- `PropositArgumentEngine.fromServerData` signature shrinks: `(snapshot, claims, claimCitations)` — `domainSources` parameter removed.
- `getDomainSource` / `getDomainSources` / `setDomainSource` / `removeDomainSource` accessors removed. Citation claims now live in `claimsMap` alongside normal claims; consumers filter `Object.values(claims).filter(c => c.type === "citation")` for citation-only views.
