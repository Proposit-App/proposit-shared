A published argument a user has set aside to return to later, on their own account and across every device they sign in from. A saved argument names the argument, never a particular version, so it always resolves to whatever the argument's current published version is — "find it again" means the argument as it stands, not the revision that happened to be current when it was saved. Distinct from a reaction: saving expresses intent to come back, not an opinion about the content, and a user may save their own arguments as freely as anyone else's.
