# Changelog — v0.44.0

<changes starting-hash="1744708" ending-hash="d64c9e9">

## Added

- New sub-path `@proposit/shared/engine/derive`: `counterargumentPremiseIds`,
  `attackTargetsByClaimId` (+ `TAttackTarget`), `wrappedOperatorExpressionIds`,
  `citationsByClaimId`, `loneRebuttalTargets`, `partitionItemsByTab`
  (+ `TArgumentTab`), `findLoneConclusion` (+ `TLoneConclusion`),
  `REPAIRABLE_CODES`, `detectRepairs`; re-exports `getClaimProofState` /
  `TClaimProofState` from `argument-metrics`. Ported byte-identical from the
  canonical server/mobile copies (server-first on divergence).
- New sub-path `@proposit/shared/engine/render`: `buildArgumentFormula`
  (+ `TArgumentFormula`, `TPremiseFormula`), `serializeArgumentToMarkdown`,
  `serializeArgumentText` (+ `TArgumentHeader`), and the citation display
  projection `humanizeCitationTypeMap` / `humanizeCitationType` /
  `getInlineSourceLabel` / `describeSource` (+ `TSourceDetail`) / `parseByline`.
- New sub-path `@proposit/shared/engine/algebra`:
  `mergeWithAddedModifiedReconciliation`, `nextVariableSymbol`.
- New sub-path `@proposit/shared/engine/overlay`: the ATV item model
  (`TAtvItem`, `TAtvSlotItem`, `TAtvOperatorItem`, `TOperatorLabelEdge`,
  `buildAtvEditableItems`, `collectOperatorLabelEdges`), the ghost item type
  (`TAtvGhostItem`), and the skeleton overlay (`applySkeletonOverlay`,
  `nextSkeletonOperator`, `TAtvSkeletonItem`, `TAtvOverlayItem`,
  `TSkeletonOverlayContext`) plus re-exports of the skeleton-inference
  primitives. The diff-driven ghost builders stay per-client (they consume each
  client's own diff/graph layer); only the item model lifts.
- Exported golden fixtures + tests (`src/engine/__tests__/derived-view*.ts`) that
  lock the derived output byte-for-byte for downstream consumer validation.
- `@proposit/shared/engine/optimistic` now also exports the optimistic
  claim-reaction reducer graduated from the clients: `bucketOf`, `applyStance`,
  `clearOwn`, and types `TStanceBucket` / `TClaimReactionState`. Ported
  byte-identical from mobile's tested `claim-stance-state`; server and mobile
  delete their local copies on their adoption slices. Locked by exported stance
  goldens in `derived-view-goldens.ts` + a golden assertion test.
- New sub-path `@proposit/shared/schemas/api/mutation-conflict`: a
  machine-readable 409-equivalent conflict envelope
  (`MutationConflictResponseSchema` / `TMutationConflictResponse`,
  `MutationConflictCodeSchema` / `TMutationConflictCode`) with discriminator
  `error: "MUTATION_CONFLICT"` and a `code` enum
  (`ALREADY_PUBLISHED`, `PUBLISHED_VERSION_NOT_ARCHIVABLE`,
  `PUBLISH_VERSION_CONFLICT`) for the argument publish/archive mutations, plus the
  `isMutationConflictError` guard re-exported from `@proposit/shared/api-client`
  (mirrors the grammar-violations envelope + `isGrammarViolationsError`). Additive
  contract only; server emits and mobile narrows on their adoption slices.
- `parseResponse` (`src/utils/utils.ts`) now auto-detects the MUTATION_CONFLICT
  409 envelope in its default (2-arg) form and returns it as
  `ParsedError<typeof MutationConflictResponseSchema>` — mirroring the
  GRAMMAR_VIOLATIONS 422 auto-detect. Previously a 409 conflict body fell through
  to `Value.Parse(ErrorResponseSchema, …)`, which threw (the envelope lacks
  `errorID`/`errorMessage`/`statusCode`), leaving `isMutationConflictError`
  unreachable. Callers now narrow the surfaced `result.error` with
  `isMutationConflictError`. The 3-arg explicit-error-schema form is unchanged.

## Changed

- `@proposit/proposit-core` peer dependency range bumped to `^3.0.0`
  (dev-pinned to the 3.0.0 publish-candidate tarball for local build/test).
- Normalized two bare `crypto.randomUUID()` sites (`engine.ts`,
  `engine/mutations/premises.ts`) to `globalThis.crypto.randomUUID()` so the
  platform global is feature-gated consistently.

## Docs

- Ratified the import-vs-ingestion naming split in the taxonomy
  (`docs/taxonomy/ingestion-pipeline`): import is the user-facing verb, ingestion
  is the internal pipeline vocabulary. No code rename.
