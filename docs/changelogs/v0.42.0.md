# Changelog — v0.42.0

## Changed

- Tightened input validation on the auth wire schemas
  (`@proposit/shared/schemas/api/auth`). Runtime constraints only — the derived
  `TMobileSessionRequest` / `TEmailCodeRequest` types are unchanged.
    - `email` fields (both `EmailCodeRequest.email` and the `{ provider: "email" }`
      `MobileSessionRequest` member) now carry `minLength: 3`, `maxLength: 254`
      (RFC 5321), and `pattern: "^[^@\s]+@[^@\s]+$"`. Rejects `""`, over-long
      emails, and values with no `@`. `format: "email"` is intentionally not used
      (TypeBox no-ops unregistered formats).
    - `code` (the `{ provider: "email" }` member) is pinned to a six-digit code:
      `minLength: 6, maxLength: 6, pattern: "^[0-9]{6}$"`.
    - `testing-and-qa` `identity` now carries `minLength: 1, maxLength: 254`.
