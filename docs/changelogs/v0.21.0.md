# v0.21.0

## Run-level `errorData` on the pipeline-status run object

`PipelineRunSchema` (`schemas/api/pipeline-status`) gains an
`errorData: Nullable(Type.Record(Type.String(), Type.Unknown()))` field,
mirroring the loose `tasks.errorData` column so the
`GET /api/v1/task/[taskId]/pipeline` response can carry the persisted
run/task-level failure cause (e.g. `{ code: "PIPELINE_FAILED", message }`);
`null` for runs that did not fail below the stage level. Additive to the wire
shape, but a required key (`Nullable`, not `Optional`) — every producer of a run
object must now emit it. Consumed by proposit-server's task-page outcome banner.
Commit `2872e76`.
