# Changelog — v0.18.0

## New

- `listTasks(query?)` api-client method — `GET /api/v1/task` for the
  authenticated user's tasks, with optional query params. Registered in
  `factory.ts`; builds the URL via `URLSearchParams`, omitting absent params
  (no literal `undefined`), and routes through the no-payload `strictFetch`
  form (mirrors `searchUserClaimsImpl`).
- New export subpath `@proposit/shared/schemas/api/task-list`, exporting
  `ListTasksQuerySchema` / `TListTasksQuery` (optional `argumentId` UUID,
  `version`, `limit` 1–50 default 20, `offset` ≥0 default 0; defaults are
  server-applied, never injected into the URL) and `ListTasksResponseSchema` /
  `TListTasksResponse` — `{ tasks: TTask[]; hasMore: boolean }`, where `tasks`
  is the full `TaskSchema` union (a user's list spans every task type, unlike
  retry/cancel which narrow to `ArgumentCreateTask`).
