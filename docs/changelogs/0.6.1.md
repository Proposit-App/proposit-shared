# Changelog — v0.6.1

Commit range: `v0.6.0` → `v0.6.1`. Patch release exposing the v0.10/v0.11 type discriminators on `TTextTreeItem` so consumers can render `CITATION` and `DERIVATION` badges without re-walking the snapshot.

## Engine helpers (`@proposit/shared/engine/text-tree`)

- `TTextTreeItem`'s `claim` variant now carries `claimType: "normal" | "citation"`, and the `premise-header` variant carries `premiseType: "freeform" | "derivation"`. `buildTextTree` populates both from the snapshot, so consumers no longer need to look up the discriminator from `snapshot.claims[claimId]?.type` / `snapshot.premises[premiseId]?.premise?.type` at render time.
- Additive change — existing callers continue to work.

## Tests

- Extended: `src/engine/__tests__/text-tree.test.ts` — asserts `claimType` / `premiseType` on emitted items, including a citation-typed claim case.
