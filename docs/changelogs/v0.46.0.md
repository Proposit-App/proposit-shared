# Changelog — v0.46.0

<changes starting-hash="3cebcbe" ending-hash="d25f365">

## Added

- `@proposit/shared/engine/review/overlay`: `buildInlineReviewOverlay(params: {
  argEngine, reactions, overrides })` — resolves the inline argument-text-view
  review overlay. Per claim it computes `effective = override ?? reaction ??
  default` (default via core `deriveDefaultAssignment()` translated to claim
  keys) and `provenance = (override||reaction) ? "user" : "default"`, then feeds
  the merged assignment to `evaluate()` with every operator accepted (axiom-bound
  keys stripped, citation-bound kept) to carry claim-keyed propagated
  (`unknown → true`) values and the `TCoreEvaluationGrade`.
- `@proposit/shared/engine/review/types`: `TAssignmentProvenance = "user" |
  "default"`, and additive `TReviewOverlay` fields `claimProvenance?:
  Record<string, TAssignmentProvenance>`, `claimPropagatedValues?:
  Record<string, TCoreTrivalentValue>` (claim-keyed), and `grade?:
  TCoreEvaluationGrade`. All optional — the existing wizard `buildReviewOverlay`
  is unchanged and leaves them undefined.

## Changed

- Bumped the `@proposit/proposit-core` peer requirement to `^3.1.0` (the
  usage-based default derivation, `getVariableIdForClaim` /
  `getClaimIdForVariable`, and `gradeEvaluation` this builds on). The dev
  dependency points at a local `3.1.0` tarball for validation; it reverts to the
  registry range at publish.

</changes>
