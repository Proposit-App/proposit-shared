# Changelog — v0.17.0

## Breaking changes

- `PipelineStageSchema`: field `outcome` renamed to `status` (wire-format
  breaking change).
- `PipelineStageOutcomeSchema` renamed to `PipelineStageStatusSchema`.
- `TPipelineStageOutcome` renamed to `TPipelineStageStatus`.

## New

- `PipelineStageStatusSchema` now includes `"pending"` and `"running"` literals
  alongside the existing `"completed"`, `"skipped"`, `"failed"`, and `null`.
- `PipelineStageSchema.responseId: string | null` — the latest attempt's OpenAI
  response id; null for non-OpenAI stages or pre-v0.17.0 rows.
- `PipelineStagePayloadSchema.responseId: string | null` — the per-attempt
  OpenAI response id; null for non-OpenAI attempts or pre-v0.17.0 rows.
