# Changelog — v0.41.0

## Added

- `MobileSessionRequest` (`@proposit/shared/schemas/api/auth`) gains two union
  members alongside the existing `google | apple | x`:
    - `{ provider: "email", email: string, code: string }` — the email
      one-time-code verify step.
    - `{ provider: "testing-and-qa", identity: string }` — a credential-less
      reviewer/QA login.
      Additive: existing OAuth requests still validate.
- `EmailCodeRequest` + `TEmailCodeRequest`
  (`@proposit/shared/schemas/api/auth`) — `{ email: string }` with
  `additionalProperties: false`; the OTP request-code step. Not a member of
  `MobileSessionRequest` (it issues no session).
- `EmailCodeResponse` + `TEmailCodeResponse`
  (`@proposit/shared/schemas/api/auth`) — constant `{ status: "sent" }`,
  non-enumerating so it never reveals whether the email maps to an account.
