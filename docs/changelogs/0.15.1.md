# v0.15.1 changelog

`v0.15.1` lands the `@proposit/shared` half of **slice D** of the
pipeline-refinement initiative (post-v0.17.2 design) — a canonical 402
error-body contract for token-budget exhaustion. Patch release, additive
only.

## Schemas — new api/errors module (slice D 402 contract)

- **Add:** `src/schemas/api/errors.ts`. Flat-file schema module
  (matching the `grammar-violations.ts` convention). Exports
  `BudgetExceededErrorBodySchema` — the canonical body returned by every
  LLM-bearing entry route when the caller's per-user token budget is
  exhausted (HTTP 402) — and its derived `TBudgetExceededErrorBody` type.
  Shape: `{ code: "TOKEN_BUDGET_EXCEEDED", message, usage: { used,
limit, resetOn } }`. `used`/`limit` are non-negative integers;
  `resetOn` is an ISO-8601 date-time. The literal `code` matches the
  task-level settle code emitted for mid-pipeline overruns
  (`TaskStatus.FAILED` with `errorData.code === "TOKEN_BUDGET_EXCEEDED"`)
  so the client has one classifier across the request-level and
  task-level surfaces.
- **Add:** `src/schemas/__tests__/errors.test.ts` — 7 TypeBox tests:
  a valid body passes `Value.Check`; missing `usage`, string `usage.used`,
  non-literal `code`, non-integer `usage.used`, and negative `usage.limit`
  are rejected by `Value.Check`; a non-date-time `resetOn` is rejected by
  `Value.Parse` (format is enforced on parse, not on check, per the
  repo's established convention).
