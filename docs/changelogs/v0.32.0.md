# Changelog — upcoming

## Changed

- `BaseTaskSchema`: `startedOn` → `startedAt`, `completedOn` → `settledAt`. `createdOn` is
  unchanged.
- `PipelineRunSchema.finishedAt` → `settledAt`; `PipelineStageSchema.finishedAt` → `settledAt`.
- `PipelineStageSchema`: added `warnings: TProcessingFailure[]`, a sibling of `failures`.
  Callers currently reading warning-severity entries out of `failures` should switch to
  `warnings` once the producing side (`proposit-server`) writes the split.

## Breaking

- The old field names (`startedOn`, `completedOn`, `finishedAt`) are no longer part of these
  schemas. Consumers pinned to the previous minor must update at the same time they bump.
