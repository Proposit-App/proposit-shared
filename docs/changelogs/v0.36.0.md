# v0.36.0

## Added

- `ClaimReactionMapResponse` + `TClaimReactionMapResponse`
  (`src/schemas/api/claim-reaction/index.ts`): a
  `Type.Record(Type.String(), ClaimReactionGetResponse)` mapping each `claimId`
  in an argument version to its `{ counts, own }` snapshot. Reuses the existing
  single-claim GET shape as the map value.
- `getClaimReaction(argumentId, version, claimId)` on the api-client factory:
  `GET /api/v1/argument/{argumentId}/{version}/claim/{claimId}/reactions`,
  validated against `ClaimReactionGetResponse`.
- `getClaimReactionMap(argumentId, version)` on the api-client factory:
  `GET /api/v1/argument/{argumentId}/{version}/claim-reactions`, validated
  against `ClaimReactionMapResponse`.

Both methods mirror the existing GET client style (no request body,
`parseResponse` on the response). Purely additive — existing callers are
unaffected.
