# v0.15.2 changelog

`v0.15.2` relaxes the citation-claim branch of the entire-argument
response schema so url-only citation claims validate. Patch release,
backward-compatible widening only.

## Schemas — CitationClaimSchema citation field widened to nullable

- **Modify:** `src/schemas/model/claims.ts`. `CitationClaimSchema.citation`
  changed from `IEEEReferenceSchema` to `Nullable(IEEEReferenceSchema)`.
  v2 ingestion produces url-only citation claims (`url` present, no
  structured IEEE reference → `citation: null`); the read path in
  `proposit-server`'s `getCitations` returns exactly that shape. The
  pre-0.15.2 non-null requirement made every such claim fail validation,
  500ing `GET /api/v1/argument/[id]/[v]/entire`. Full structured IEEE
  citations remain valid — this is a widening, not a replacement. The
  `url` string discriminates the citation branch, so a null `citation`
  does not collide with the normal/axiomatic branches of `ClaimSchema`.
  Derived type `TCitationClaim["citation"]` widens to
  `TIEEEReference | null`.

## Tests

- **Modify:** `src/schemas/__tests__/claims.test.ts`.
    - **Add:** `CitationClaimSchema` accepts a url-only citation claim
      (`citation: null`) — the failing-test-first capture of the bug.
    - **Add:** `CitationClaimSchema` rejects a citation claim missing the
      `citation` field entirely — the field stays required, only its value
      may be null.
    - **Add:** `ClaimSchema` (union) accepts a url-only citation-variant
      claim — regression guard for the entire-argument response path, where
      the claims array is `Type.Array(ClaimSchema)`.
    - The pre-existing "accepts a well-formed citation claim" test (full
      IEEE `citation`) remains and still passes — no-regression guard.
    - Removed the now-incorrect "rejects a citation claim with null
      citation" test (it enshrined the bug).

## Test and check state

## Out of scope

- No `proposit-mobile` work — mobile is not a direct consumer of this

- No upstream `proposit-core` change — `IEEEReferenceSchema` is unchanged.
