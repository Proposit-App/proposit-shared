# Changelog — v0.5.1

Commit range: `v0.5.0` → `v0.5.1`. Patch release fixing four schema-level bugs surfaced by `proposit-server`'s adoption of `@proposit/shared@0.5.0`.

## Schema fixes

- `fix: nullable citation, drop ClaimCitation.version, optional premise role, restore default premiseFields` — `ClaimSchema.citation` accepts `null`; `ClaimCitationSchema` drops the leftover top-level `version` field; `ArgumentEngineSnapshotSchema` premise `role` is optional; `CHECKSUM_CONFIG.premiseFields` falls back to `DEFAULT_CHECKSUM_CONFIG` (4 fields) instead of the shared-side 6-field override.
- Tests added: nullable-citation round-trip, citation-edge no-version parse, role-less snapshot parse, `premiseFields` regression check.
- Test fix-ups: dropped `version` from `engine.test.ts`'s `makeClaimCitation` fixture; switched `verification.test.ts`'s divergence trigger from `premise.title` to `premise.argumentVersion` (title is no longer in the premise checksum).
