# Changelog — v0.19.0

> Requires `@proposit/proposit-core` `^2.0.0`.

## Breaking changes

- `@proposit/shared/schemas/model/references` now re-exports the IEEE
  reference types from `@proposit/proposit-core/extensions/citations/ieee`
  (was `@proposit/proposit-core/extensions/ieee`). This follows the core
  `2.0.0` move of IEEE references under the `citations` extension namespace.
  Consumers importing IEEE types via `@proposit/shared` are unaffected; only
  the underlying core subpath changed.

## New

- Two-tier citation model. `references` additionally re-exports the unparsed
  citation type from `@proposit/proposit-core/extensions/citations/unparsed`
  (`UnparsedCitationSchema` / `TUnparsedCitation`), the
  ingestion-extracted-but-not-yet-structured tier.
- `CitationClaimSchema.citation` widened to
  `Nullable(Union([IEEEReferenceSchema, UnparsedCitationSchema]))`. The `type`
  discriminant (the IEEE literals vs `"unparsed"`) keeps the union
  unambiguous; `null` remains the url-only citation claim. This is a
  widening — existing full-IEEE citations stay valid.
- `extractCitationTitle` (`@proposit/shared/utils`) now handles the
  `{ type: "unparsed", text, url? }` citation: it prefers `text`, falling back
  to the optional `url` when `text` is empty. The former `"UnparsedURL"` case
  is removed (that shape no longer exists in core `2.0.0`); the legacy
  `{ type: "Other", text? }` case is retained.
