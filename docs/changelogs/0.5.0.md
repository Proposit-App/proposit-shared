# Changelog — v0.5.0

Commit range: `v0.4.0` → `v0.5.0`. Implementation per `docs/superpowers/plans/2026-05-06-core-0.11-upgrade.md`.

## Core dep + Layer 1 wire-up

- `feat: bump @proposit/proposit-core to ^0.11.0 (Layer 1 wire-up)` — bumps core dep, drops `sourceLookup` constructor arg, threads `type: "normal"` placeholder through `toCoreClaim` and the permissive-restore stub, drops `SourceManagerSnapshotSchema` and `sources` field from the engine snapshot wire format, re-syncs `TCoreValidationCodeSchema` enum against core@0.11.0, premise fixtures and `createPremiseWithId` callsites thread `type: "freeform"`.

## ClaimSchema.kind rename + engine domainSources removal

- `feat: ClaimSchema.kind rename + drop engine domainSources machinery` — `ClaimSchema.type` → `kind`; new required `type: "normal" | "citation"` discriminator; optional `url`/`citation`/`citationContentHash` extras; `ClaimTypes`/`ClaimTypesSchema`/`TClaimTypesSchema` → `ClaimKinds`/`ClaimKindsSchema`/`TClaimKindsSchema`; `ClaimSearchResultSchema.type` → `kind`. Engine: `sourcesMap`, `getDomainSource*`, `setDomainSource`, `removeDomainSource`, `domainSources` field on `TProjectReactiveSnapshot` and `fromServerData` all gone. `toCoreClaim` widens input type and threads `c.type`.

## Source-to-citation rename

- `refactor: source-to-citation rename (schema + engine accessor sweep)` — deletes `schemas/model/sources.ts`, introduces `schemas/model/citations.ts` with `ClaimCitationSchema = Type.Intersect([CoreClaimCitationSchema, app fields])`. Engine: `claimSourcesMap` → `claimCitationsMap`; `addClaimSource` → `addClaimCitation`; `getSourcesForClaim` → `getSourceClaimsForCitingClaim`; `getClaimSources` → `getClaimCitations`; `removeClaimCitation(edgeId)` (single first-class edge id). `ArgumentDiff` drops `sources`, renames `claimSources` → `claimCitations`. `FullArgumentSchema` likewise. `SourceForkSchema` → `CitationForkSchema`; `TClaimSource` → `TClaimCitation` everywhere.

## API client + REST + utility/quota renames

- `refactor: API client + REST surface + utility/quota renames` — file renames (`schemas/api/sources.ts` → `citations.ts`; `api-client/user/sources.ts` → `citations.ts`); function renames (`createClaimSourceImpl` → `createClaimCitationImpl`; `deleteClaimSourceImpl` → `deleteClaimCitationImpl`; `searchUserSourcesImpl` → `searchUserCitationsImpl`; `getUserSourcesImpl` → `getUserCitationsImpl`); REST path flips; `extractSourceTitle` → `extractCitationTitle`; `ObjectLimitTypes` `"sources"` → `"citations"`; `maxSourcesPerArg` → `maxCitationsPerArg` across all 7 tier rows.

## v0.11 derivation re-exports + tests

- `feat: re-export v0.11 derivation surface via engine/derivation` — new `engine/derivation.ts` reachable through the existing `./engine/*` exports glob. Re-exports `ManagedDerivationPremiseEngine`, `validateDerivationStructure`, `TVariableMaterializer`, error code constants. Tests: smoke for re-exports, premise type discriminator schema parse, legacy data rejection.

## Version + docs

- `chore: bump version to 0.5.0` — `package.json` version bumped; `docs/release-notes/upcoming.md` and `docs/changelogs/upcoming.md` rotated to `0.5.0.md`. Release notes include a comprehensive **Wire/storage shape changes** section enumerating every schema-level delta consumers need to migrate persisted data.
