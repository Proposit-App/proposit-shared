# v0.35.0

## Changed

- `MobileSessionRequest` (`src/schemas/api/auth/index.ts`) is now a `Type.Union`
  discriminated on `provider`, replacing the flat object. The existing
  `{ provider: "google" | "apple", idToken: string, nonce?: string }` shape is
  preserved unchanged as one union member.

## Added

- New `MobileSessionRequest` member `{ provider: "x", accessToken: string }` for
  mobile X (Twitter) sign-in. X uses OAuth 2.0 (PKCE), yielding an access token
  rather than an OIDC ID token, so this member carries `accessToken` and has no
  `idToken`. The wire discriminator is the literal `"x"` (not `"twitter"`; the
  stored `twitter` provider identity is a separate concept and is rejected on this
  request). `TMobileSessionRequest` narrows correctly on `provider`. Purely
  additive — existing google/apple callers are unaffected.
