# v0.25.0

- **Claim schema decoupled from the argument version (breaking).** `ClaimSchema`
  (`src/schemas/model/claims.ts`) now models a claim as an independently-versioned,
  shareable-by-reference entity:
    - `version` is documented/typed as the claim's **own trunk version** (advances
      on the claim's own content change), no longer a denormalized copy of the
      referencing argument's version.
    - `argumentId` is replaced by **nullable `originArgumentId`** (provenance only,
      `string | null`). Consumers reading `claim.argumentId` must switch to
      `claim.originArgumentId`.
    - adds **`published: boolean`** and **`publishedOn: Date | null`**, required on
      all three claim variants (`NormalClaim` / `CitationClaim` / `AxiomaticClaim`)
      via the shared base, so `ClaimSchema` and `ClaimWithChildrenSchema` carry them
      too.
- **`ClaimForkSchema` / `TClaimFork` now exported** (`src/schemas/model/forks.ts`).
  Previously defined but re-exported nowhere; now importable from
  `@proposit/shared/schemas` via a re-export through the claims model entry
  (mirrors the existing `ArgumentForkSchema` re-export). No new export sub-path.
- Excluded the tcw-managed `docs/work` tree from prettier (`.prettierignore`),
  parallel to the existing `docs/inbox` ignore.
