# v0.10.0 changelog

`v0.10.0` is the small coordinated minor of `@proposit/shared` that unblocks server's cycle 4b (advanced-mode setting) and cycle 4c (validation gates) in the cross-repo Grammar Tiers initiative. Three additions, one branch, no engine-wrapper churn.

## Schemas — user-record + modify-request

- **Modify:** `src/schemas/model/users.ts` — `UserSchema` gains a required `advancedMode: Type.Boolean()` field. DB-side `NOT NULL DEFAULT false` column is owned by server's coordinated cycle-4b migration; this is purely the wire-format declaration. Commit `3a3062c`.
- **Modify (breaking):** `src/schemas/api/user/index.ts` — `UserModifyRequest` changes from `Type.Object({ username: Type.String() })` to `Type.Object({ username: Type.Optional(Type.String()), advancedMode: Type.Optional(Type.Boolean()) })`. Body becomes "any one writable field" rather than always-username. Server enforces "at least one writable field present" as an out-of-schema concern. Commit `3a3062c`.

## API-client — grammar-violations type guard

- **Add:** `src/api-client/grammar-violations.ts` — new `isGrammarViolationsError(err: unknown): err is TGrammarViolationsResponse` type-guard. Narrows via the stable `error: "GRAMMAR_VIOLATIONS"` discriminator. Commit `3a3062c`.
- **Modify:** `src/api-client/index.ts` — re-exports `isGrammarViolationsError` alongside `createApiClient`, `TApiClient`, `TApiClientConfig`. Consumers import from `@proposit/shared/api-client`. Commit `3a3062c`.

## Tests

- **Add:** `src/api-client/__tests__/grammar-violations.test.ts` — 9 tests for `isGrammarViolationsError`: positive cases (derivable D-3 envelope, presentable empty envelope), negative cases (`TErrorResponse`-shaped object, wrong discriminator string, no `error` key, `null`, `undefined`, primitives, arrays). Commit `3a3062c`.
- **Modify:** `src/api-client/user/__tests__/delete-user.test.ts` — `SAMPLE_USER_JSON` fixture gains `advancedMode: false` to satisfy the widened `UserSchema`. Commit `3a3062c`.
