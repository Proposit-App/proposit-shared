# Changelog — v0.40.0

## Added

- `citationImport(url, referenceType)` api-client method
  (`@proposit/shared/api-client`) — wraps the server
  `POST /api/v1/citation/import` route to fetch + extract source metadata from a
  URL. Its response schema is a **nullable union**
  (`Type.Union([CitationImportResponseSchema, Type.Null()])`) so a failed
  extraction (the route returns `200` + `null`) resolves to `{ ok: true, value:
null }` instead of throwing in `parseResponse`.
- `CitationImportResponseSchema` + `TCitationImportResponse`
  (`@proposit/shared/schemas/model/references`) — `{ websiteTitle, pageTitle,
byline }`, mirroring the server's source-analysis shape.
