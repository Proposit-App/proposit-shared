Sign in with an email address and password. Proposit does not give user accounts passwords, so this path is intentionally unsupported — sign in through an identity provider instead, or with a one-time code sent to your email.

(Non-user-facing exception: `testing-and-qa` accounts do carry a password, because App Store review requires the demo credentials given to a reviewer to be a username and a password. It is not reachable as a user sign-in.)
