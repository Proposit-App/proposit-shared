Create an argument by importing source content — paste a block of prose and choose an analysis depth — and have it parsed into a draft argument.

The imported text is kept as the argument's source text, and each premise and claim the import produces is linked back to the passage it came from. An argument imported from a platform also gets its source text attributed automatically, with nothing to fill in. An imported argument is only ever treated as having *started* from its source, never as claiming to represent it — that is a declaration the author makes deliberately, afterwards.
