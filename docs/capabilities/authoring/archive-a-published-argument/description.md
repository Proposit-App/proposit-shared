Archive an argument I have already published, freezing it at its last published
version. Archiving discards the working draft: an argument with no draft is what
the product calls archived, and no further changes can be made to it.

The draft is destroyed outright, not set aside. Nothing retains it and nothing
restores it — there is no archived or deleted state to come back from. The
published versions are untouched and stay readable.

A published version cannot itself be archived. Asking to archive one is refused
as a conflict rather than silently doing nothing.
