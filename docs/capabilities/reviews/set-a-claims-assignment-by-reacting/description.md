Reacting to a claim (agree, disagree, or unsure) sets that claim's review
assignment: agree makes it true, disagree false, unsure unknown. The assignment
follows my reaction lazily — if I change my reaction the assignment moves with
it, and if I clear the reaction it falls back to the usage-based default.

Making an explicit assignment in review pins the value: it takes precedence over
my reaction and the default until I clear it. Reacting and assigning stay
independent — assigning in review never changes my reaction, and reacting never
creates a review assignment record.
