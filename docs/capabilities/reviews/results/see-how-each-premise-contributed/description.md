Beyond the two assessments, I can see how the argument got there: the value the
conclusion came out to, and what each premise did on the way.

For each supporting premise I see the value it took and what its inference
actually did — including the case where it is satisfied but passed nothing on,
because the thing it depends on doesn't hold. That is reported as a fact about
this evaluation, not as a verdict on the premise; the verdict is the argument
assessment's job.

A premise I rejected is shown as **struck** — removed from the set the argument
was worked out from — never as a premise that came out false. Rejecting a step
says its reasoning doesn't carry, which asserts nothing about the truth of what
it concludes, so reporting it as false would put a claim in my mouth I never
made.

For each restriction premise I see whether the values I supplied sit inside the
constraint I granted, are outside it, or are not yet settled. A conflict says a
resolution is needed; it does not say anyone erred.
