An explanation in the abstract is hard to hold on to, so each assessment comes
with a worked example: a one-sentence everyday scenario, a tiny argument that
produces exactly this assessment, and the assessment it comes out to.

The example argument is drawn in Proposit's own notation — the same claim cards,
the same operator label between them, the same true / false / unknown pills, the
same marking of which claim is the conclusion — so what I learn from reading the
example transfers directly to reading my own argument. It is small enough to take
in at a glance: two or three claims, one or two operators.

The example is plainly an example. It never blends into my argument, it is never
mistaken for my own decisions, and nothing in it is editable.

Scenarios are chosen from ordinary life rather than from logic textbooks, so the
reader who needs the example most can follow it.
