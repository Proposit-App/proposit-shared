My assessment reports what follows from the values I supplied. From the results I
can ask a stronger question: is there **any** assignment of values, mine or not,
where every premise holds and the conclusion still does not?

The check runs over every combination and answers plainly — either no failing
case exists, or here are the ones that do. Each failing case is spelled out in
the argument's own words: which claim takes which value. It is never handed to me
as raw data to decode.

The check is exhaustive, so it is only offered on arguments small enough to
finish it. When an argument is too large I am told that, rather than being given
a partial answer that reads like a complete one; when a run is cut short, the
result says so.

A failing case is a fact about the argument's form, not about my review, and
finding one changes nothing I decided.
