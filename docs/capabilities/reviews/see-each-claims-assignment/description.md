Reading an argument, I see a small true / false / unknown chip on each claim
showing its current review assignment. A badge on the chip tells me where that
value came from: a **filled** badge means it is my own input (a reaction I left
or an assignment I made in review), an **outline** badge means it is a default
the system derived from how the claim is used — grounded claims (citations,
axioms, and the claims they directly support) start true, while claims still to
be proven start unknown.

When the argument evaluates, a claim that starts unknown but is transitively
grounded shows its propagated "unknown → true" state on the chip, so I can watch
support flow through the argument.
