Some arguments have premises that cannot all hold at once, whatever values a
reader supplies. When I open a review of one, I am told at the start, in plain
terms, which of its premises conflict — before I spend a walkthrough assigning
values that could never come out consistent.

Being told never blocks me. I can still work through every claim and premise and
finish my review. Nothing is worked out from those premises, because there is no
consistent set of values to work anything out from, so the argument assessment
reads that its premises contradict each other rather than reporting a reach it
cannot support.

The notice describes the conflict itself. It does not lay it at anyone's feet.
